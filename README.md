# MyScreenTime
Приложение, позволяющее отслеживать экранное время проведённое за ПК

# Для установки приложения на Windows
1. Скачайте архив ScreenTimeV1.rar
2. Распакуйте содержимое архива в удобное для вас место
3. Запустите install.exe от имени администратора
4. Пройдите все пункты в установщике
5. Перезагрузите ПК с помощью установщика или самостоятельно
