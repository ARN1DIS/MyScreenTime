# MyScreenTime
Приложение, позволяющее отслеживать экранное время проведённое за ПК

# Для установки приложения на Windows
1. Установите Chrome
2. Скачайте архив ScreenTimeV1.rar
3. Распакуйте содержимое архива в удобное для вас место
4. Запустите install.exe от имени администратора
5. Пройдите все пункты в установщике
6. Перезагрузите ПК с помощью установщика или самостоятельно
